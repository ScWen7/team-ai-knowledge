# WeKnora design reference

V0.4 references the architecture and public documentation of:

- Repository: https://github.com/Tencent/WeKnora
- Commit: 7fa6f028fcea9e08720db1f565ec4911ea0e7aa6
- Upstream project license: MIT, with additional third-party notices in the upstream repository.

V0.4 uses WeKnora as a **design reference only** for:

- stable source identity and revisions;
- source logical path vs storage path;
- versioned processing configuration;
- structured chunks and locators;
- evidence correction/revision concepts;
- evidence-grounded Wiki compilation;
- explicit processing stages.

No WeKnora implementation code is copied into V0.4.
